# 俺のラブコメはこんなはずじゃなかった

美少女ゲームやエロゲーをメタる、笑いあり涙ありの青春ラブコメディ小説。

[コンテンツ](https://kmizu.github.io/ore-no-lovecome-ha-konnna-hazu-ja-nakatta)

## 概要

高校2年生のゲームオタク・神崎悠真と、10年来の幼馴染・白河美月の、ゲーム的な視点を交えながらも地に足の着いた温かい恋愛物語。

- 全33章 + 付録
- 総文字数：約94,000文字
- MkDocs + Material テーマで構築

## セットアップ

### 必要環境

- Python 3.8以上
- pip

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/kmizu/ore-no-lovecome-ha-konnna-hazu-ja-nakatta.git
cd ore-no-lovecome-ha-konnna-hazu-ja-nakatta

# 依存関係をインストール
pip install -r requirements.txt

# または
pip install -e .
```

## 使い方

### ローカルでプレビュー

```bash
# MkDocsの開発サーバーを起動
mkdocs serve

# ブラウザで http://127.0.0.1:8000 を開く
```

### サイトをビルド

```bash
# 静的サイトを生成
mkdocs build

# siteディレクトリにHTMLファイルが生成される
```

## 章構成

### 第1部 日常編（第1章〜第11章）
幼馴染との日常と、恋心の自覚

### 第2部 波乱編（第12章〜第22章）
転校生の登場と関係の試練

### 第3部 完結編（第23章〜第33章）
二人の選択と未来への歩み

## GitHub Pages へのデプロイ

このリポジトリはGitHub Actionsを使用して自動的にGitHub Pagesにデプロイされます。

`main`ブランチにプッシュすると、自動的にサイトが更新されます。
